关于 IP 动态感知

只观测、不封禁、不改防火墙、不自动处置：把散落的访问与扫描日志收成一张能点的地图。

使用说明

  • 首次打开请在「设置」填地图 KEY、选底图服务商，按需开启数据源。
  • 点地图圆点或记录表任一行，查看该 IP 的完整来源画像。
  • 出问题时到「设置」最底部一键导出运行报错与运行日志诊断包。

注意事项

  1. 地图 KEY 需自行申请，未配置时只显示不绘边界的坐标散点示意。
  2. 归属结果为离线库与在线源交叉校验，仅供参考，不作处置依据。
  3. 本应用不提供实时防护，请勿用于封 IP、改防火墙或自动处置。
  4. 软件永远不改防火墙设置：需要处置时，在「IP 来源画像」写标注加入提交单，复制读取提示词交给外部 agent 按标注直接执行（1.1.27 起仅争议项才二次确认）。
  5. 1.1.27 起提交单可查看密钥授权（指纹 / 公钥 / 时间 / 设备），1.1.28 起入口移到右上角，点开才显示；你随时可以撤销并删除设备上的私钥。
  6. 提交 Issue 请用导出的脱敏文件，勿直接贴 config.json / events.db。
